# Código de conducta

Portfolio Tracker es un proyecto personal abierto a correcciones y propuestas. Quien participa en sus issues y pull requests se compromete a mantener un trato respetuoso.

## Qué esperamos

- Respeto hacia las personas, sea cual sea su experiencia, origen, identidad o forma de expresarse.
- Críticas dirigidas al código y a las ideas, nunca a quien las propone.
- Aceptar con naturalidad que una propuesta no encaje y que una revisión pida cambios.

## Qué no se admite

- Insultos, burlas, acoso o comentarios discriminatorios.
- Publicar datos personales de otras personas sin su permiso.
- Insistir de forma hostil tras una respuesta negativa.

## Qué ocurre si no se cumple

Quien mantiene el proyecto puede editar u ocultar comentarios, cerrar issues y pull requests y, si se repite, bloquear la participación de la cuenta.

## Cómo avisar

Si ves un comportamiento que no encaja con este código, usa la opción **Report content** de GitHub en el comentario o escribe a quien mantiene el proyecto a través de su [perfil de GitHub](https://github.com/RaclosDev).

Este texto se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
